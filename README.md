# 🛡️ mptcp-check — проверка и защита сервера от уязвимости MPTCP

Лёгкий Bash-скрипт, который **за один запуск** определяет, уязвим ли ваш Linux-сервер к атаке через MPTCP (Multipath TCP), и при необходимости **автоматически закрывает уязвимость**.

## ⚡ Быстрый старт

Одна команда — и готово:

```bash
curl -sSL https://raw.githubusercontent.com/dmk87/security-tools/main/mptcp-check.sh | sudo bash
```

> **Требуется root:** без `sudo` скрипт выполнит проверку, но не сможет применить защиту (запись в `/etc/sysctl.d/` и `sysctl -w`).

Классический вариант — скачать, посмотреть, запустить:

```bash
curl -O https://raw.githubusercontent.com/dmk87/security-tools/main/mptcp-check.sh
less mptcp-check.sh          # убедитесь, что перед вами тот самый код
chmod +x mptcp-check.sh
sudo ./mptcp-check.sh
```

## 🔍 Что делает скрипт

1. **Определяет ОС** — читает `/etc/os-release` (дистрибутив и версию).
2. **Проверяет статус MPTCP** — через `sysctl net.mptcp.enabled` либо `/proc/sys/net/mptcp/enabled`.
3. **Сверяет версию ядра с патченными релизами** по таблице ниже.
4. **Выдаёт вердикт** одним из трёх цветов и, если система уязвима, **сразу применяет временную защиту**.

## 📊 Поддерживаемые дистрибутивы и пороги патчей

| Дистрибутив | Версия | Уязвимость закрыта начиная с |
|---|---|---|
| Ubuntu | 24.04 | ядро `6.8.0-155` и новее |
| Ubuntu | 22.04 | ядро `5.15.0-210` и новее |
| Debian | 12 | `6.1.190` и новее |
| Debian | 13 | `7.2.12` и новее |
| RHEL / AlmaLinux / Rocky | 9 | сборка ядра `5.14.0-503` и новее |
| RHEL / AlmaLinux / Rocky | 10 | считается защищённой |

## 🚦 Возможные вердикты

| Вердикт | Что это значит | Что происходит |
|---|---|---|
| 🟢 `[БЕЗОПАСНО]` | Патчи ядра установлены | Ничего — система защищена |
| 🟢 `[ЗАЩИЩЕНО]` | Патчей нет, но MPTCP уже отключён | Ничего — эксплойт невозможен |
| 🔴 `[УЯЗВИМО]` | MPTCP включён, патчей нет | **Автоматическая защита**: `net.mptcp.enabled=0` + запись `99-disable-mptcp.conf` в `/etc/sysctl.d/` |

Пример вывода:

```
=== Универсальная проверка и защита сервера (Debian/Ubuntu/RHEL/Alma) ===
[УЯЗВИМО] Система уязвима! MPTCP включен, патчей нет. Применяем защиту...
[ВРЕМЕННАЯ ЗАЩИТА ПРИМЕНЕНА] MPTCP отключен. Рекомендуется обновить ядро!
```

## 🧰 Как устроена защита

Скрипт не отключает MPTCP «вслепую», а только когда это действительно нужно:

```bash
sysctl -w net.mptcp.enabled=0                          # мгновенно, до перезагрузки
echo "net.mptcp.enabled = 0" >> /etc/sysctl.d/99-disable-mptcp.conf   # переживёт перезагрузку
```

Отключение MPTCP не влияет на обычную работу сети: протокол используется лишь для агрегации нескольких путей соединения. Если он вам не нужен — вы ничего не заметите.

## ⚠️ Важные замечания

- **Временная защита — не замена патчу.** Обновите ядро (`apt update && apt upgrade` / `dnf update`) и перезагрузитесь, чтобы вернуться к постоянному решению.
- Скрипт только читает состояние системы и отключает MPTCP. Он **не** меняет другие настройки, не удаляет файлы и не касается сетевых правил.
- Перед запуском любого стороннего кода загляните в него глазами — исходник открыт и занимает около 50 строк.

## 📄 Лицензия
