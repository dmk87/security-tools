# Security Tools 🛡️

Набор утилитарных скриптов для автоматического аудита безопасности, проверки обновлений ядра и оперативного устранения критических уязвимостей на Linux-серверах.

## 🚀 MPTCP Security Check (`mptcp-check.sh`)

Универсальный Bash-скрипт для проверки статуса протокола **MPTCP** (MultiPath TCP) и наличия актуальных патчей безопасности в ядре операционной системы. 

### Поддерживаемые дистрибутивы
* **Ubuntu** (22.04, 24.04)
* **Debian** (12, 13)
* **RHEL-like** (RHEL 9/10, AlmaLinux, Rocky Linux)

### Что делает скрипт?
1. **Анализирует систему:** Точно определяет дистрибутив, версию ОС и текущую сборку ядра.
2. **Проверяет патчи:** Сверяет установленную версию ядра с базой безопасных релизов.
3. **Автоматически защищает:** Если система уязвима и MPTCP активен, скрипт безопасно отключает его на лету через `sysctl` и фиксирует настройки в `/etc/sysctl.d/99-disable-mptcp.conf`.

## 💻 Быстрый запуск (One-Liner)

Вы можете запустить аудит безопасности удаленно на любом сервере одной командой без предварительного скачивания файлов:

```bash
curl -sSL https://githubusercontent.com | tr -d \('\r' \vert{}\) sudo bash
```

> **Примечание:** Утилита `tr -d '\r'` добавлена в конвейер для автоматического удаления Windows-переносов строк, если файл редактировался на ПК под управлением Windows.

---

## 🛠️ Локальный запуск

Если вам необходимо сохранить скрипт на сервере для регулярных проверок:

```bash
# Скачивание файла
curl -O https://githubusercontent.com

# Очистка от Windows-символов (при необходимости)
sed -i 's\(/\r//'\) mptcp-check.sh

# Установка прав на исполнение
chmod +x mptcp-check.sh

# Запуск
sudo ./mptcp-check.sh
```
