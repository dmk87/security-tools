## 1. 🔍 `php-fastpanel-check.sh` — аудит PHP, FASTPANEL и обновлений ОС

Диагностический скрипт в режиме **только для чтения** (ничего не меняет и не перезагружает). Проверяет актуальность пакетов FASTPANEL, выявляет неперезапущенные после обновления процессы `php-fpm` (критично для уязвимостей **PHP2Shell**), проверяет наличие патчей безопасности ОС и ищет подозрительные процессы во временных директориях.

### ⚡ Быстрый старт

Одна команда — и готово:

```bash
curl -sSL https://githubusercontent.com | tr -d '\r' | sudo bash
```

> **Требуется root:** без `sudo` скрипт не сможет прочитать параметры запущенных процессов других пользователей и проверить системные пакеты.

Классический вариант — скачать, посмотреть, запустить:

```bash
curl -O https://githubusercontent.com
less php-fastpanel-check.sh          # убедитесь, что перед вами тот самый код
chmod +x php-fastpanel-check.sh
sudo ./php-fastpanel-check.sh
```

### 🔍 Что делает скрипт

1. **Определяет ОС и ядро** — выводит версию Ubuntu или Debian, версию ядра и имя хоста.
2. **Проверяет статус FASTPANEL** — отображает установленные сборки `fastpanel2` и внутреннего `fastpanel2-fphp`.
3. **Проводит аудит всех версий PHP** — сравнивает дату последнего обновления PHP-пакетов на диске со временем старта каждого мастер-процесса `php-fpm` в памяти.
4. **Проверяет обновления безопасности ОС** — показывает ожидающие патчи безопасности для Ubuntu/Debian и статус Ubuntu Pro / ESM.
5. **Ищет признаки компрометации** — сканирует запущенные процессы из директорий `/tmp` и `/dev/shm`.

### 🚦 Возможные вердикты по процессам PHP

| Вердикт | Что это значит | Что делать |
|---|---|---|
| `[ОК]` | Процесс `php-fpm` запущен **после** обновления пакетов | Ничего — патч применён в памяти |
| `[ОПАСНО - НУЖЕН РЕСТАРТ]` | Файлы обновились, но процесс в памяти старый | Принудительно перезапустить службу `php-fpm` |

### 🧰 Быстрое исправление (если нужен рестарт PHP)

Если скрипт показал статус `[ОПАСНО - НУЖЕН РЕСТАРТ]`, обновите пакеты и перезапустите все службы PHP-FPM одной командой:

```bash
sudo apt update && sudo apt upgrade -y && systemctl list-units --type=service --all | grep -E "php.*fpm" | awk '{print $1}' | xargs -r sudo systemctl restart
```

## 2. 🛡️ `mptcp-check.sh` — проверка и защита сервера от уязвимости MPTCP

Лёгкий Bash-скрипт, который **за один запуск** определяет, уязвим ли ваш Linux-сервер к атаке через MPTCP (Multipath TCP), и при необходимости **автоматически закрывает уязвимость**.

### ⚡ Быстрый старт

Одна команда — и готово:

```bash
curl -sSL https://raw.githubusercontent.com/dmk87/security-tools/main/mptcp-check.sh | tr -d '\r' | sudo bash
```

> **Требуется root:** без `sudo` скрипт выполнит проверку, но не сможет применить защиту (запись в `/etc/sysctl.d/` и `sysctl -w`).

Классический вариант — скачать, посмотреть, запустить:

```bash
curl -O https://raw.githubusercontent.com/dmk87/security-tools/main/mptcp-check.sh
less mptcp-check.sh          # убедитесь, что перед вами тот самый код
chmod +x mptcp-check.sh
sudo ./mptcp-check.sh
```

### 🔍 Что делает скрипт

1. **Определяет ОС** — читает `/etc/os-release` (дистрибутив и версию).
2. **Проверяет статус MPTCP** — через `sysctl net.mptcp.enabled` либо `/proc/sys/net/mptcp/enabled`.
3. **Сверяет версию ядра с патченными релизами** по таблице ниже.
4. **Выдаёт вердикт** одним из трёх цветов и, если система уязвима, **сразу применяет временную защиту**.

### 📊 Поддерживаемые дистрибутивы и пороги патчей

| Дистрибутив | Версия | Уязвимость закрыта начиная с |
|---|---|---|
| Ubuntu | 24.04 | ядро `6.8.0-155` и новее |
| Ubuntu | 22.04 | ядро `5.15.0-210` и новее |
| Debian | 12 | `6.1.190` и новее |
| Debian | 13 | `7.2.12` и новее |
| RHEL / AlmaLinux / Rocky | 9 | сборка ядра `5.14.0-503` и новее |
| RHEL / AlmaLinux / Rocky | 10 | считается защищённой |

### 🚦 Возможные вердикты

| Вердикт | Что это значит | Что происходит |
|---|---|---|
| 🟢 `[БЕЗОПАСНО]` | Патчи ядра установлены | Ничего — система защищена |
| 🟢 `[ЗАЩИЩЕНО]` | Патчей нет, но MPTCP уже отключён | Ничего — эксплойт невозможен |
| 🔴 `[УЯЗВИМО]` | MPTCP включён, патчей нет | **Автоматическая защита**: `net.mptcp.enabled=0` + запись `99-disable-mptcp.conf` в `/etc/sysctl.d/` |

Пример вывода:

```
=== Универсальная проверка и защита сервера (Debian/Ubuntu/RHEL/Alma) ===
[УЯЗВИМО] Система уязвима! MPTCP включен, патчей нет. Применяем защиту...
[ВРЕМЕННАЯ ЗАЩИТА ПРИМЕНЕНА] MPTCP отключен. Рекомендуется обновить ядро!
```

### 🧰 Как устроена защита

Скрипт не отключает MPTCP «вслепую», а только когда это действительно нужно:

```bash
sysctl -w net.mptcp.enabled=0                          # мгновенно, до перезагрузки
echo "net.mptcp.enabled = 0" >> /etc/sysctl.d/99-disable-mptcp.conf   # переживёт перезагрузку
```

Отключение MPTCP не влияет на обычную работу сети: протокол используется лишь для агрегации нескольких путей соединения. Если он вам не нужен — вы ничего не заметите.

## ⚠️ Важные замечания

- **Временная защита для MPTCP — не замена патчу.** Обновите ядро (`apt update && apt upgrade` / `dnf update`) и перезагрузитесь, чтобы вернуться к постоянному решению.
- Скрипт `php-fastpanel-check.sh` работает строго в режиме чтения и **не** вносит изменений в конфигурацию без вашего участия.
- Перед запуском любого стороннего кода загляните в него глазами — исходники обоих скриптов открыты.

## 📄 Лицензия

Свободное использование. Проверьте код перед запуском — вы отвечаете за свой сервер 🙂
